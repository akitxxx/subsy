# 俳句ジェネレーター

スラッシュコマンドのテストのために、指定された季節（または引数なし）でランダムな俳句を1つ生成してください。

引数: $ARGUMENTS

以下のルールで俳句を生成してください：
1. 5-7-5の音律を厳密に守る
2. 季語を必ず含める
3. プログラミングやコードに関する単語を1つ以上含める（例：コード、デバッグ、コンパイル、変数、関数など）
4. ユーモアを含める

生成した俳句を以下の形式で出力してください：

```
🍃 本日の俳句 🍃
================
[生成した俳句]
================

季語：[使用した季語]
プログラミング要素：[使用したプログラミング関連の単語]
```

最後に「このコマンドはスラッシュコマンド機能のテストです」と明記してください。
